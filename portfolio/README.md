# Portfolio

React rebuild of Christian's portfolio site (originally vanilla HTML/CSS/JS, preserved read-only in `../old-reference/`).

## Stack

React 19 · Vite · Tailwind CSS v4 · daisyUI 5 · React Router v7 · Framer Motion · tsParticles

## Getting started

```bash
cd portfolio
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Scripts

- `npm run dev` — start the dev server with HMR
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
